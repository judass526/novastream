# NovaStream — Proyecto web estático

Sitio demo de streaming con películas, series, anime, documentales e infantil. No requiere backend ni base de datos.

## Ver el proyecto

Abre `index.html` en tu navegador.

Opcional:

```bash
npx serve .
```

## Funciones

- Páginas separadas: Inicio, Películas, Series, Anime, Documentales, Infantil, Mi Lista, Login y Planes.
- Al pulsar ▶ o el póster se abre una ficha animada.
- Es obligatorio iniciar sesión para reproducir.
- Progreso guardado en el navegador.
- Mi Lista persistente.
- Animaciones al hacer scroll, hover y al abrir detalles.
- Página 404, favicon y SEO básico.

## Editar catálogo

Abre `js/data.js` y agrega objetos a `CATALOG`.

## Publicar

Sube todos los archivos a GitHub Pages, Netlify, Vercel o Cloudflare Pages.
